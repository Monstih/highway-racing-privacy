# highway-racing-privacy

Legal documents of Highway Racing (`com.halogames.highwayracing`), published with GitHub Pages:

| Document | English | Русский |
| --- | --- | --- |
| Privacy Policy / Политика конфиденциальности | [index.html](index.html) — `https://monstih.github.io/highway-racing-privacy/` (Play Console URL) | [ru/index.html](ru/index.html) |
| Terms of Use / Пользовательское соглашение | [terms.html](terms.html) | [ru/terms.html](ru/terms.html) |

The game opens the Russian pages for the Russian language and the English pages otherwise
(`[/Script/highwayracing.HWLegalSettings]` in the game's `Config/DefaultGame.ini`). The Russian text prevails.
A material change needs a new version date here and a higher `RequiredConsentVersion` in the game, which asks
every player to accept the documents again.
